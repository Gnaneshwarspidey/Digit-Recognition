2. Abstract
Handwriting recognition is a classic computer-vision problem with applications in postal automation, bank cheque processing, form digitisation, and education. This project develops a Convolutional Neural Network (CNN) that recognises handwritten digits (0–9) using the MNIST dataset and handwritten characters (letters and digits) using the EMNIST dataset. The system pre-processes input images (grayscale conversion, resizing to 28×28, normalisation), extracts hierarchical features using convolution and pooling layers, and classifies them using fully connected layers with a softmax output. Regularisation techniques such as dropout, batch normalisation and data augmentation are used to improve generalisation. The model targets above 99% accuracy on MNIST and above 85–90% on EMNIST Balanced. A simple web/desktop interface lets a user draw or upload a character and receive the predicted class with a confidence score.
Keywords: CNN, Deep Learning, Handwritten Recognition, MNIST, EMNIST, Image Classification, TensorFlow, Keras

3.2 Problem Statement
Manual transcription of handwritten digits and characters is slow, error-prone and costly. Traditional rule-based and classical ML approaches (e.g., SVM on hand-crafted features) struggle with the wide variation in handwriting style, slant, thickness and noise. A CNN-based system can learn features directly from pixels and generalise across writers.

6.3 Important Data Note
EMNIST images are stored transposed (rotated/flipped) compared to normal orientation. Before training or visualising, fix the orientation (e.g., transpose each image) so user-drawn images match the training data.

9.3 Model Code (Keras)
from tensorflow.keras import layers, modelsdef build_cnn(num_classes):    model = models.Sequential([        layers.Input(shape=(28, 28, 1)),        layers.Conv2D(32, 3, padding='same'), layers.BatchNormalization(), layers.ReLU(),        layers.Conv2D(32, 3, padding='same'), layers.BatchNormalization(), layers.ReLU(),        layers.MaxPooling2D(), layers.Dropout(0.25),        layers.Conv2D(64, 3, padding='same'), layers.BatchNormalization(), layers.ReLU(),        layers.Conv2D(64, 3, padding='same'), layers.BatchNormalization(), layers.ReLU(),        layers.MaxPooling2D(), layers.Dropout(0.25),        layers.Flatten(),        layers.Dense(256, activation='relu'), layers.Dropout(0.5),        layers.Dense(num_classes, activation='softmax'),    ])    model.compile(optimizer='adam',                  loss='sparse_categorical_crossentropy',                  metrics=['accuracy'])    return model
9.4 Training Code (MNIST)
from tensorflow import kerasfrom tensorflow.keras.callbacks import EarlyStopping, ModelCheckpoint, ReduceLROnPlateaufrom model import build_cnn(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()x_train = (x_train.astype('float32') / 255.0)[..., None]x_test  = (x_test.astype('float32') / 255.0)[..., None]model = build_cnn(10)callbacks = [    EarlyStopping(patience=5, restore_best_weights=True),    ModelCheckpoint('models/mnist_cnn.keras', save_best_only=True),    ReduceLROnPlateau(factor=0.5, patience=2),]history = model.fit(x_train, y_train, validation_split=0.1,                    epochs=30, batch_size=128, callbacks=callbacks)print(model.evaluate(x_test, y_test))

9.7 User Image Preprocessing
import cv2, numpy as npdef prepare_image(img):    # img: 2-D uint8 grayscale array    if img.mean() > 127:            # white background -> invert to match MNIST        img = 255 - img    _, img = cv2.threshold(img, 30, 255, cv2.THRESH_TOZERO)    ys, xs = np.where(img > 0)    if len(xs) == 0:        raise ValueError('Blank image')    img = img[ys.min():ys.max()+1, xs.min():xs.max()+1]       # crop to character    h, w = img.shape; s = max(h, w)    square = np.zeros((s, s), np.uint8)    square[(s-h)//2:(s-h)//2+h, (s-w)//2:(s-w)//2+w] = img   # pad to square    img = cv2.resize(square, (20, 20))    img = np.pad(img, 4)                                      # 28x28 with border    return (img.astype('float32') / 255.0).reshape(1, 28, 28, 1)

15. Conclusion & Future Scope

Question
Short answer
1
What is a CNN?
A neural network that uses convolution layers to automatically learn spatial features from images.
2
Why CNN instead of a plain MLP?
CNNs share weights, preserve spatial structure and need far fewer parameters, giving better accuracy on images.
3
What does a convolution layer do?
Slides filters over the image to detect local patterns like edges and curves.
4
Why pooling?
Reduces spatial size and computation, and gives small translation invariance.
5
Why ReLU?
Simple, reduces vanishing gradients, speeds up training.
6
Why softmax at the output?
Converts scores to probabilities across classes that sum to 1.
7
Which loss did you use and why?
Categorical cross-entropy, suited to multi-class classification with softmax.
8
What is dropout?
Randomly disables neurons during training to reduce overfitting.
9
What is batch normalisation?
Normalises layer inputs per batch, stabilising and speeding up training.
10
MNIST vs EMNIST?
MNIST has only digits (10 classes); EMNIST extends it with letters (and digits) in multiple splits.
11
Why are EMNIST images rotated?
They are stored in a transposed orientation, so they must be transposed back before use.
12
How did you prevent overfitting?
Dropout, batch norm, augmentation, early stopping, validation monitoring.
13
Why is accuracy lower on EMNIST?
More classes and many visually similar pairs (O/0, I/l, g/q).
14
What is a confusion matrix?
A table of actual vs predicted classes, revealing which classes are confused.
15
Why Adam optimiser?
Adaptive learning rates and momentum give fast, stable convergence.
16
Why is real hand-drawn accuracy lower than test accuracy?
Distribution shift in stroke width, position, background and noise; reduced by preprocessing and augmentation.
17
What is an epoch / batch size?
One full pass through the training data / number of samples per weight update.
18
How can you improve the model further?
Deeper networks, ensembles, more augmentation, transfer learning, tuning.
19
What are the limitations?
Single character only, 28×28 input, no cursive or multi-script support.
20
How will you extend it?
CRNN with CTC for words, regional scripts, TFLite for mobile.
